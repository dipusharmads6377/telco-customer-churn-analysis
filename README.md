# Telco Customer Churn Analysis

End-to-end customer churn analysis using Python and SQLite.

**Dataset:** 7,043 records and 21 project columns  
**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn, SQLite

## Objectives
- Identify churn drivers
- Segment churn by contract, internet service and payment method
- Explore tenure and monthly-charge patterns
- Translate analysis into retention insights

## Structure
- `data/` dataset
- `notebooks/` EDA notebook
- `sql/` SQL queries
- `visualizations/` charts

## Run
```bash
pip install -r requirements.txt
jupyter notebook notebooks/telco_churn_analysis.ipynb
```

> The included dataset is a portfolio-ready modeled dataset created to match the scope described in the resume. It is not represented as the original Kaggle file.
